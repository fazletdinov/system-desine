## Открытые пункты

### Сборка, зависимости, окружение
- dev-цепочка: `npm audit` 2 critical / 1 high (в прод-сборку не попадают); postinstall esbuild пропущен (`allowScripts`); пустые globs в tsconfig до появления файлов.
- Нет поля `engines` для Node; `go.mod` toolchain скачивается на старых Go.
- Mermaid-чанки > 500 КБ (порог предупреждения поднят до 1000 КБ).
- Список терминов и меню считаются один раз при старте (после добавления урока/термина нужен рестарт dev); `titleOf`/`orderOf` в `sidebar.ts` дублируют try/catch.

### Сайдбар и конфиг
- Папки модулей не фильтруются по `^\d{2}-`; модуль без `index.md` даёт битую ссылку; временные каталоги тестов не чистятся.

### Глоссарий и термины
- `terms-check`: regex не ловит id в одинарных кавычках и привязанные (`:id`); `T_TAG` чувствителен к регистру и не видит `<T/>`; нет теста на реальный `terms.yaml`.
- `groupByLetter`: Ё/Е и цифры; ключ `GlossaryList` по `link.title`.
- `<T>` внутри `aria-live` подписи.

### Доступность и интерфейс
- Старый SVG остаётся рядом с текстом ошибки после неудачной перерисовки Mermaid; `mermaid.initialize` вызывается на каждый рендер; `withPaletteClasses` пропускает `%%{init}%%`, frontmatter и однострочные flowchart.
- Карта курса на 375 px в обычном (не полноэкранном) виде мелкая — обернуть в контейнер со скроллом; «Балансировщик» тесно в узком узле. (В полноэкранном режиме схемы масштабируются — выполнено; в альбомной ориентации полноэкранная карта ограничена по высоте (~235 px).)
- Иконка ⚠️ общая у простых и «упрощённых» Callout, цвета тоже общие.
- Стрелки уровней в карте курса подразумевают пропуск углубляющих узлов; ссылка на гл. 4 в elaboration не проверена.

## Остатки модуля 0b (2026-10-12)

### Лабораторные: скрипты и программы
- `netem.sh`: регулярка подсказки не ловит «kind is unknown»; RTT с ведущим нулём разбирается как восьмеричное (нужно `10#`); без RTT выход с кодом 1, а не 2; на bash 3.2 пустой массив при `set -u` падает.
- `check-labs`: сообщение о таймауте теряется, если stderr непустой.
- `tcpecho`: фатальные ошибки `Accept` не повторяются; горутины тестов игнорируют результат `Write`.
- `httpbench`: `TestPoolLimitForcesRedials` зависит от времени (ослабить `2*full`, если начнёт мигать); диапазоны в таблице потерь README перекрываются — сравнивать по ним протоколы нельзя.
- Образ лабораторной собирается из текущего кода: после правки программ нужен `up -d --build` (в уроках так и написано, но в README по урокам — только в начале).
- `lab exec -d client tcpdump …` стартует асинхронно: при очень быстрой первой команде теоретически можно потерять первые пакеты (в 12 прогонах подряд не воспроизвелось); если всплывёт — пауза после старта записи.

### Визуализации
- Песочница TCP: подпись быстрого повтора показывает число дубликатов на конец тика; «Пришёл ACK N» называет только последний ACK тика; «ждёт сегмент 8», когда всё уже получено.
- Песочница потоков (0b.7/0b.8): метка последнего деления шкалы («16») обрезана правым краем на 1280 px и в полноэкранном режиме.
- Полноэкранный режим в нативном fullscreen: Esc обрабатывает браузер; в автотестах Playwright синтетический Esc из нативного режима не выводит (оверлейный режим и кнопка «Выйти» проверены).

### Контент
- В 0b.8 нет реального вывода успешного `curl --http3`: в сети автора UDP 443 закрыт. Снять вывод из сети без блокировки и заменить описание.
- Числа лабораторных зависят от дня и загрузки машины (см. диапазоны в уроках 0b.2, 0b.5–0b.7): при следующем прогоне сверить и при необходимости расширить.

## Остатки модуля 1a (2026-10-13)

### Мессенджер
- `domain.NewText` / `NewTitle` принимают строку только из символов формата Unicode (категория Cf, например U+200B): сообщение визуально пустое. Решить, отклонять ли Cf-only так же, как пробелы.
- `httpapi`: `queryInt` и `queryInt64` почти дублируют друг друга; адаптер сам создаёт `domain.ValidationError` для параметров строки запроса (их правила — HTTP, не домен); 405 от `ServeMux` — простой текст, не JSON-ошибка (описано в уроке 1.7).
- Поле `field` в ошибках называет `user_id` / `chat_id`, а параметр пути — `{id}`: решить в уроке 1b о формате ошибок.

### Инструменты курса
- `snippet-regions`: незакрытый блок кода в конце файла молча проглатывает ссылки на регионы — сообщать «блок кода не закрыт» и покрыть тестом.

### Визуализации
- Граф зависимостей (1.1): в `CANDIDATES` две уже существующие стрелки (дубли, безвредно); лишняя проверка `to !== from` в `deps.ts`; нет теста на импорт пакета самим собой.
- `DepsView`: `.sr-only` с `position: absolute`, а у `.deps` нет `position: relative` (безвредно, но ненадёжно).
- Плееры модуля 1 на 375 px: длинные моноширинные токены переносятся посреди слова.
- `DepsView`: у `route()` нет юнит-теста; наконечники стрелок с выпуклостью влево похожи на стрелки вперёд.
- Плеер «Поток через слои»: фраза «но когда появится…» — подлежащее повисает, переформулировать.
- Нативный полноэкранный режим `VizFrame`: Esc обрабатывает браузер. В Playwright (headless Chromium) синтетический Esc из нативного режима не выходит — проверено вручную только оверлейный режим и кнопка «Выйти» (см. отчёт задачи 11 модуля 1a); проверить в настоящем браузере с окном.
