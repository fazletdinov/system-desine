# Визуальный язык курса

Все визуализации используют одни и те же цвета и обозначения. Цвета задаются только через переменные из `palette.css` — для светлой и тёмной темы.

| Сущность | Переменная | Обозначение |
|---|---|---|
| Клиент (телефон, браузер) | `--viz-client` | прямоугольник со скруглением |
| Сетевой узел (DNS, балансировщик) | `--viz-network` | прямоугольник со скруглением |
| Сервис (Go) | `--viz-service` | прямоугольник со скруглением |
| База данных | `--viz-db` | прямоугольник со скруглением |
| Кэш (Redis) | `--viz-cache` | прямоугольник со скруглением |
| Брокер (Kafka) | `--viz-broker` | прямоугольник со скруглением |
| Запрос | `--viz-request` | движущийся круг |
| Ответ | `--viz-response` | движущийся круг |
| Ошибка | `--viz-error` | движущийся круг + красная рамка узла |
| Активный узел | `--viz-active` | толстая рамка |
| Связь | `--viz-edge` | линия |

Правила:
- у каждого шага есть пояснение на русском;
- анимация отключается при `prefers-reduced-motion`;
- текст внутри SVG на ширине экрана 375 px должен иметь экранный кегль не меньше 12 px. SVG там занимает около 290 px, поэтому `font-size` ≥ 12 × ширина `viewBox` / 290. Если широкая схема этому не удовлетворяет, нужна отдельная узкая раскладка (как в `RequestPathView.vue`);
- всё, что трогает DOM или GSAP, выполняется только на клиенте (`onMounted`, `watch` без `immediate`).

## Классы Mermaid

В блоках ```` ```mermaid ```` с `flowchart`/`graph` доступны классы узлов. Пример: `A[Телефон]:::client --> B[Go-сервис]:::service`.
Блоки `classDef` добавляются автоматически, писать их в уроке не нужно. Цвета живут в `viz/core/mermaid-palette.ts` (Mermaid не читает CSS-переменные).

| Класс | Смысл |
|---|---|
| `client` | клиент: телефон, браузер |
| `service` | сервис на Go |
| `db` | база данных |
| `cache` | кэш (Redis) |
| `broker` | брокер сообщений (Kafka) |
| `network` | сетевой узел: DNS, балансировщик |
| `deep` | углубление: необязательный материал (пунктирная рамка) |
| `error` | ошибка, авария: паника, отказ (красная рамка, `--viz-error`) |

## Шкала задержек

| Уровень | Переменная |
|---|---|
| `cpu` | `--viz-service` |
| `memory` | `--viz-cache` |
| `disk` | `--viz-db` |
| `network` | `--viz-network` |

Здесь цвет означает уровень иерархии памяти, а не тип узла: диск окрашен как БД, потому что обычно именно там живут данные, но это не «база данных» на схеме.

## Флейм-граф

| Чей код в блоке | Переменная |
|---|---|
| мессенджер (`messenger/…`, `main`) | `--viz-service` |
| стандартная библиотека | `--viz-client` |
| рантайм Go (`runtime`, `internal/runtime/…`, ассемблер) | `--viz-network` |
| сторонний модуль (`golang.org/x/…`, `github.com/…`) | `--viz-cache` |
| «прочее» — слитые мелкие стеки | пунктир `--viz-muted` |

Совпадение поиска — толстая рамка `--viz-text`, а не цвет: цвет уже занят смыслом «чей код».

## Полноэкранный режим

- Каждая сцена и схема оборачивается в `VizFrame` (`viz/components/VizFrame.vue`); логика выбора режима — в чистом модуле `viz/core/fullscreen.ts`.
- В полноэкранном режиме контейнер плеера шире 900 px, и код встаёт справа сам — через container query.
- Оверлей (`position: fixed` поверх страницы) — запасной вариант для iPhone Safari и для случая, когда браузер отказал в `requestFullscreen`.

## Снимки экрана (`<Shot>`)

Настоящий снимок программы с окнами с пометками, как в книге: `course/components/Shot.vue`, логика — в чистом модуле `shot.ts`.

- Файл — WebP в `course/public/shots/<урок>/`, путь в уроке — от корня сайта: `src="/shots/…"` (base добавляет компонент). Как снимали и как переснять — `course/public/shots/README.md`.
- `:width`/`:height` — размеры файла: из них viewBox пометок; `check:refs` сверяет их с файлом.
- `:marks` — `{ n, x, y, w?, h?, text }`, координаты в процентах от снимка. С `w`/`h` — рамка (левый верхний угол в `x, y`), номер встаёт снаружи рамки; без них `x, y` — центр кружка. `text` — пояснение под снимком с тем же номером, код — в обратных кавычках.
- Цвет пометки — `--course-accent` (подсветка курса), ореол — `--vp-c-bg`: пометка читается и на светлом, и на тёмном снимке.
- Клик по снимку открывает его на весь экран через `VizFrame`; пояснения тогда встают колонкой справа.
